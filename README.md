# Civil Ledger ⚖️
### *The Independent Truth Engine for South African Private Security Workers*

**Civil Ledger** is a lightweight, secure, and cross-platform digital timesheet system built to eliminate systemic wage theft, learnership fraud, and illegal payroll manipulation within the private security sector. 

Built by a security officer for security officers, it runs **100% offline with zero data or Wi-Fi costs**, storing data locally on the user's phone to serve as an unalterable record of truth.

---

## 🛠️ System Architecture & Legal Logic
1. **Statutory Hours Isolation:** Automatically parses shifts into Ordinary Hours (capped at **208 hours**), Overtime (1.5x), Sundays (1.5x/2x), and Holidays (2x) matching **Sectoral Determination 6**.
2. **Shared-Device Security Matrix:** Allows multiple guards to securely access their portable profiles from a single borrowed phone using a 5+ digit PIN or Physical Address, featuring input masking (`•••••`) and an automated **2-minute idle session timeout**.
3. **Anonymous Site-Batching:** Encrypts and batches local hour logs into site-wide compliance datasets, allowing state inspectors to cross-examine corporate payroll fraud without exposing individual whistleblowers to employer retaliation.
